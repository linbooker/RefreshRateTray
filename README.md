# RefreshRateTray

笔记本插不插电源，自动换刷新率的托盘小程序：**插着适配器切到显示器支持的最高档，用电池切到最低档**。
托盘图标上直接显示当前刷新率，一眼就能看出现在跑在几赫兹。

- 单文件 exe，.NET Framework 4.8（Windows 11 自带），**无需安装、无第三方依赖**
- 常驻内存很小（WinForms + 2 秒轮询 `GetSystemPowerStatus`，空闲时几乎不占 CPU）
- 不写系统目录、不改系统设置，只调用 Windows 标准的 `ChangeDisplaySettingsEx`
- **没有任何写死的刷新率**：档位在运行时从 Windows 枚举，换机器、换分辨率、换显示器都自动适配
- **多显示器**：自动枚举所有接在桌面上的屏幕，各按自己支持的档位切换（外接屏只有一档就固定在该档，不会被切黑）

---

## 1. 快速开始

1. 把 `dist\RefreshRateTray.exe` 复制到任意**普通目录**，例如：
   - `%LOCALAPPDATA%\Programs\RefreshRateTray\`
   - `D:\Tools\RefreshRateTray\`
2. 双击运行，托盘出现一个绿色数字 —— 当前刷新率（插电时是这块屏的最高档）。
3. 拔掉电源 → 图标变黄、数字变成最低档，屏幕随之切到最低刷新率；插回去 → 变绿、数字变成最高档。

想开机自启：右键托盘图标 → 「开机自启动」→「开启（登录后自动运行）」
（写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，随时可关）。

### 便携版（Pocket）：所有东西就一个文件夹

不想让设置在注册表里、想要「拷走即用 / 删文件夹即卸载」，用 **`Pocket\`** 文件夹：

```
Pocket\
├─ RefreshRateTray.exe           托盘主程序，双击运行
├─ RefreshRateTray.cli.exe       命令行版（可选）
├─ settings.ini                  设置（同目录，第一次改设置时自动写）
├─ app.log                       日志（运行后自动生成）
└─ README.md                     便携版说明
```

功能与标准版完全一样（多屏、运行时枚举档位、手动输入、暂停、自启），区别只有存放位置：

| | 标准版 `dist\` | 便携版 `Pocket\` |
| --- | --- | --- |
| 设置 | `HKCU\Software\RefreshRateTray` | 同目录 `settings.ini` |
| 日志 | `%LOCALAPPDATA%\RefreshRateTray\app.log` | 同目录 `app.log` |
| 自启值名 | `RefreshRateTray` | `RefreshRateTray (Pocket)` |
| 卸载 | `uninstall.ps1`（可选） | 删掉文件夹 |

两个版本共用单实例锁，不能同时运行。`--status` 第一行之后会标明当前是「标准版」还是「便携版」以及设置来源。

## 2. 托盘图标与菜单

| 图标 | 含义 |
| --- | --- |
| **绿色** + 数字 | 交流电源，数字为当前刷新率 |
| **黄色** + 数字 | 电池供电，数字为当前刷新率 |
| **灰色** + `--` | 读不到当前刷新率，或已暂停自动切换 |

左键或右键点图标都会弹出菜单：

- **当前状态**（只读，例：`当前 <数字> Hz · 交流电源`，接了多块屏时显示 `· N 个屏幕`）
- **立即切换 ▸**：列出**所有显示器支持的刷新率并集**，外加一项 `手动输入…`。
  点哪个立刻把所有屏幕切过去。这只是临时手动切换，**不会**改动「适配器/电池」的目标值
- **自动切换**：勾选式开关。取消勾选后程序只显示不干预
- **暂停自动切换 ▸**：`15 分钟` / `30 分钟` / `1 小时` / `2 小时` / `4 小时` / `暂停直到手动恢复`；
  已暂停时子菜单最上面多一项 `立即恢复自动切换（剩余 …）`
- **适配器时使用 ▸**：
  - `自动（最高刷新率）` ← 默认，按显示器实际能力取最高档
  - 该屏实际支持的各个档位（点一下即生效并保存）
  - `手动输入…`（1–480 之间任意值，显示器不支持时自动退到最接近的档）
- **电池时使用 ▸**：同上，默认是 `自动（最低刷新率）`
- **开机自启动（已开启/已关闭）▸**：`开启（登录后自动运行）` / `关闭`
- **退出**

设置保存在 `HKCU\Software\RefreshRateTray`：

| 键 | 含义 | 默认 |
| --- | --- | --- |
| `AcHz` | 插电时的目标刷新率，`0` = 自动取最高 | `0` |
| `BatteryHz` | 电池时的目标刷新率，`0` = 自动取最低 | `0` |
| `Auto` | 是否按电源自动切换，`1`/`0` | `1` |

删掉整个键即恢复默认（自动最高 / 自动最低 / 自动切换开）。

## 3. 命令行用法

同一份源码另编了一个控制台版 `dist\RefreshRateTray.cli.exe`，方便脚本调用或排查：

```bat
RefreshRateTray.cli.exe --status               :: 电源 / 目标 / 每块屏的当前与目标刷新率
RefreshRateTray.cli.exe --list                 :: 列出每块显示器支持的刷新率
RefreshRateTray.cli.exe --set <Hz>             :: 立刻把所有屏切到指定值（不启动托盘）
RefreshRateTray.cli.exe --test                 :: 自检：最低档 -> 最高档 -> 恢复原值
RefreshRateTray.cli.exe --ac <Hz|0>            :: 「适配器时」目标，0 = 自动最高
RefreshRateTray.cli.exe --battery <Hz|0>       :: 「电池时」目标，0 = 自动最低
RefreshRateTray.cli.exe --icon-preview a.png   :: 把托盘图标渲染成预览图
RefreshRateTray.cli.exe --help
```

`--status` 输出示例（数字来自运行时枚举，不是写死的）：

```
电源: 交流电源
目标: 自动(最高)
自动切换: 开启
<显示器名>（主）: 当前 <N> Hz -> 目标 <N> Hz，支持 <a>, <b>, <c> Hz
```

## 4. 它是怎么判断电源的

`GetSystemPowerStatus()` 的 `ACLineStatus`：1 = 插着适配器，0 = 电池，255 = 未知（未知时不动）。
程序每 2 秒读一次，只有状态**变化**时才真正切刷新率；如果两次轮询间隔超过 10 秒（说明刚睡醒），
会重新应用一次目标值，避免唤醒后系统把刷新率恢复成默认。

显示器列表每 30 秒重枚举一次（插拔外接屏、改分辨率后支持的档位会变），打开菜单时也会立即重读。

目标刷新率不在某块屏的支持列表里时（手动输入了一个该屏没有的档位），
会自动退到**最接近的一档**，不会把屏幕切黑。目标值 `0` 表示自动：插电取该屏最高、电池取该屏最低。

## 5. 已知限制

- 只处理**挂在桌面上的显示器**；投影模式（复制/仅第二屏）下按 Windows 报告的各屏能力分别应用。
- 混合显卡机器上内屏通常挂在核显下，程序按系统报告的显示器名操作，跟独显无关。
- 建议关掉 **动态刷新率（DRR / VRR）**。Windows 的 DRR 会在多个档位之间自己跳，
  和本程序抢控制权，表现是「设了最高档但系统显示更低」。设置 → 系统 → 屏幕 → 高级显示 → 选刷新率里关。
- 全屏独占的真全屏游戏里，切换可能被游戏自己覆盖；窗口化/无边框正常。
- 某些厂商工具（荣耀电脑管家、Intel 显卡驱动面板）也会改刷新率，冲突时以最后一次调用为准。
- 同一时间只允许一个实例（同名互斥体）；换新版本后要先退出托盘里的旧实例，再运行新 exe。

## 6. 故障排查

日志：`%LOCALAPPDATA%\RefreshRateTray\app.log`（每次切换都记一行，超过 200 KB 自动重建）。

| 现象 | 原因 / 处理 |
| --- | --- |
| 托盘没有图标 | 看日志 `警告：生成托盘图标失败` |
| 切了但屏幕没变 | 检查 DRR 是否开着；或厂商工具又改回去了 |
| 插拔电源后不切换 | 菜单里「自动切换」是否被关掉、「暂停自动切换」是否生效中 |
| 图标数字和实际不符 | 刷新率被别的程序改了，程序 2 秒后会跟上；也可点「立即切换」 |
| 外接屏没跟着切 | 看日志里每块屏的 `支持` 列表；只有一档的屏会固定在该档 |

## 7. 自己编译 / 卸载

```powershell
# 重新编译（需要 .NET Framework 4.x 自带的 csc.exe，无需 SDK）
powershell -ExecutionPolicy Bypass -File build.ps1     # 标准版 -> dist\，便携版 -> Pocket\
```

可选脚本（不用也行，直接删目录就是卸载）：

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -Autostart -Start   # 装到 %LOCALAPPDATA%\Programs\RefreshRateTray
powershell -ExecutionPolicy Bypass -File uninstall.ps1                  # 停进程、删自启、删目录（保留设置）
```

源码只有一个文件：`src\RefreshRateTray.cs`（约 1870 行，C# 5 语法）。
编译开关：`/define:CLI_BUILD` 出控制台版，`/define:POCKET_BUILD` 出便携版（设置/日志放 exe 同目录），两个可以一起用。
